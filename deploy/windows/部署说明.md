# ERP 中间件 Windows 生产机部署说明

生产环境 = Windows PC，服务以隐藏窗口常驻 + 开机自启。
以下所有脚本都在 `deploy/windows/` 目录内，全部**右键 → 以管理员身份运行**（start.bat 除外）。

## 一、准备 (一次性)

1. **安装 Python 3.10+**：https://www.python.org/downloads/ ，安装时勾选 `Add Python to PATH`
2. **获取代码**（二选一）：
   - 有 git：`git clone <仓库地址>`（需要 GitHub 账号密码/令牌）
   - 没 git：Mac 上压缩项目文件夹（排除 `.venv`、`dist`、`node_modules`），拷到 PC 解压
3. **迁移配置数据**：把 Mac 上项目的
   `data/products.db`
   拷到 PC 项目同路径 `data\products.db`（货代列表、SMTP 授权码、账号、系统配置全部随库迁移，**无需在 PC 上重填任何配置**）

## 二、安装与启动

| 步骤 | 操作 | 说明 |
|---|---|---|
| 1 | 右键管理员运行 `install.bat` | 建虚拟环境 + 装依赖 + 装 Chromium（采集用）+ 防火墙放行 8000 |
| 2 | 双击 `start.bat` | 启动服务，浏览器开 `http://127.0.0.1:8000` 验证 |
| 3 | 登录 → 货代管理页点「📡 立即采集」 | 验证文档采集 + 告警链路正常 |
| 4 | 右键管理员运行 `install_autostart.bat` | 注册开机自启（隐藏窗口，SYSTEM 账户），并立即启动一次 |

完成后该 PC 重启也不需要任何人工操作。

## 三、日常管理

| 操作 | 命令/方式 |
|---|---|
| 停止服务 | 运行 `stop.bat` |
| 手动启动 | `schtasks /Run /TN "ERP-Middleware"` 或双击 `start.bat` |
| 更新代码 | `git pull`（或重新拷代码）→ `stop.bat` → `schtasks /Run /TN "ERP-Middleware"` |
| 查看运行状态 | 任务管理器找 `python.exe`，或 `netstat -ano | findstr :8000` |

## 四、局域网访问

服务监听 `0.0.0.0:8000`，同一局域网的设备访问：
`http://<这台PC的IP>:8000`（PC 的 IP 用 `ipconfig` 查看，建议在路由器里给 PC 绑定固定 IP）

## 五、文件说明

| 文件 | 作用 |
|---|---|
| `install.bat` | 环境安装（管理员） |
| `start.bat` | 前台启动（调试用） |
| `stop.bat` | 按 8000 端口杀进程 |
| `start_hidden.vbs` | 隐藏窗口拉起服务（自启任务用） |
| `install_autostart.bat` | 注册/启动开机自启任务（管理员） |
| `uninstall_autostart.bat` | 取消自启并停止服务（管理员） |

## 六、注意事项

- PC 需要**能访问外网**：`docs.qq.com`（采集）与 `smtp.163.com:465`（发邮件）
- 163 授权码与设备无关，**生产机直接沿用**，无需重新生成；切勿在 163 后台重新生成（会使旧码失效）
- 采集功能依赖 `install.bat` 里装的 Chromium，若第 4 步报错可单独重跑：`.venv\Scripts\python.exe -m playwright install chromium`
- 数据库是 SQLite 单文件，日常备份只需拷贝 `data\products.db`
