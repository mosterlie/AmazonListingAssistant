# 店小秘上件属性 × ERP 录入页字段对照清单

> 依据 `server/services/erp_bridge.py` 上件流程 `publish_product_to_erp`（2026-09-27 版）整理。
> 「ERP 录入页字段」指商品录入/编辑页（entry.html）上的展示字段名称。

## 前置流程
自动化准备（驱动清理 → 接管 Chrome 9222 → 打开店小秘添加页 → 关闭公告弹窗），无对应录入字段。

## 阶段 1：店铺与标题
| 店小秘字段 | ERP 录入页字段 | 数据来源 | 填写方式 |
|---|---|---|---|
| 店铺账号 | 店铺账号 | `store_account`（空则默认"金梧汇辰"） | 下拉选择锁定，站点联动（默认"日本"，录入页无独立站点字段） |
| 产品标题 | 产品标题 | `title` | 文本填入 |

## 阶段 2：产品分类
| 店小秘字段 | ERP 录入页字段 | 数据来源 | 填写方式 |
|---|---|---|---|
| 产品分类 | 产品分类 | `category_name` | 逐级自动匹配类目（去括号双向匹配），失败提示人工核查 |

## 阶段 3：售卖形式与品牌
| 店小秘字段 | ERP 录入页字段 | 数据来源 | 填写方式 |
|---|---|---|---|
| 售卖形式 | 售卖形式（单品/多变体单选） | `sale_type` | 点选「多变体」或「单品」 |
| Parent SKU | Parent SKU (父SKU) | `sku` | 文本填入 |
| 品牌 | 品牌 (Brand) | `brand` | 文本填入，失败转下拉选择 |
| 制造商 | 录入页无此字段，自动取品牌名 | `manufacturer`（空则用 `brand`） | 专用填入（含搜索选中逻辑） |

## 阶段 4：变体主题与矩阵
| 店小秘字段 | ERP 录入页字段 | 数据来源 | 填写方式 |
|---|---|---|---|
| 变种主题 | 变种主题 (Variation Theme)，默认「カラー/サイズ」 | `variation_theme` | 下拉选择（核心词双向匹配 + 回读验证） |
| 颜色/尺寸选项 | カラー (颜色) 选项输入、サイズ (尺寸) 选项输入 | `color_options` / `size_options` | 逐个添加标签，展开笛卡尔积矩阵 |
| 条码类型 | 变体表格 EAN 条码列 | 固定 | 变体表格第 4 列选择「EAN」 |

## 阶段 5：变体表格与图片装配
| 内容 | ERP 录入页字段 | 数据来源 | 填写方式 |
|---|---|---|---|
| 每行 SKU / EAN / 价格 / 库存 | 变体表格 SKU 编码 / EAN 条码 / 价格(JPY) / 库存 列 | 子变体对应字段（库存默认 40） | 按「颜色/尺寸」定位行填入 |
| 行尺寸重量 | 变体表格 长 / 宽 / 高 / 重量 列（进价¥ / 系数 / 快递选择仅用于定价，不上传店小秘） | — | — |
| 附图 | 附图相册（父商品级，空则取第一个有附图的变体） | `extra_images` | 第 1 个 SKU 上传 → 批量应用到全部 SKU → 校验第 2 个 SKU 生效 |
| 主图 | 变体 SKU 图片录入（按カラー/サイズ维度）+ 各行主图格 | `main_image` / `variant_image` | 逐 SKU 检查缺图 → 上传该维度对应图 → 批量应用到同维度变体 |
| 图片解析 | 录入页上传的相对路径 | — | 远程优先 `/file` 下载缓存（md5 命名），杜绝本机同名文件顶替 |

## 阶段 6：描述、配送与规格
| 店小秘字段 | ERP 录入页字段 | 数据来源 | 填写方式 |
|---|---|---|---|
| 五点描述 | 五点描述 (Bullet Points / キーポイント) | `bullet_points` | 批量填入 |
| 商品长描述 | 商品描述 (Product Description / 商品説明) | `description` | 多行无序号时自动加「1. 2. 3. …」序号 |
| 配送渠道 | 配送渠道 (Fulfillment Channel / 配送方法) | `fulfillment_channel`（默认 FBM） | 下拉锁定 FBM/FBA |
| Search Terms | Search Terms (搜索关键词 / 検索キーワード)，空则跳过 | `search_terms` | 填入搜索关键词 |
| 品目寸法 | 品目寸法（L x W x H）(商品尺寸) | `item_length/width/height` + `item_dim_unit`（默认 cm） | 三围填入 |
| パッケージ寸法 | パッケージ寸法 (包装尺寸)，录入页只读自动计算（变体尺寸乘积最大项） | `package_*` + `package_dim_unit` | 三围填入 |
| 包装重量 | 包装時の重さ (包装重量) + 商品パッケージ重量の単位，录入页只读自动计算 | `package_weight` + 单位（默认 kg） | 重量填入 |
| 商品重量 | 录入页无独立字段 | `item_weight`（由变体重量推导） | 有值才填 |

## 阶段 6.5：型号、来源与价格
| 店小秘字段 | ERP 录入页字段 | 数据来源 | 填写方式 |
|---|---|---|---|
| 品番 / 型番 | 品番・型番(型号) | `model_number` | 文本填入（动态类目渲染出哪个填哪个） |
| モデル名 | モデル名(型号名称) | `model_name` | 文本填入 |
| メーカー型番(零件编号) | 录入页无独立字段，取モデル名同值 | `model_name` | 文本填入 |
| 店小秘信息-来源URL | 源链接 (采购来源)（商品链接栏目） | `source_link` | 文本填入，未找到字段时日志提示人工核查 |
| 价目表货币 | 录入页无此字段 | 固定 JPY | 下拉选中 |
| 税込みの参考価格 | 录入页无此字段 | 全部子 SKU 价格最高价 | 文本填入 |

## 阶段 7：保存
点击【保存】存为店小秘**草稿**，不直接发布，留人工复核。上件异常时自动强杀卡死的驱动进程并标记商品失败状态。

## 补充说明
- ERP 录入页「商品链接」栏目的 **Amazon 链接**（`amazon_link`）目前仅录入存库与详情页展示，上件时不填店小秘（店小秘无对应输入项）。
- 父级商品主图/附图直接上传目前处于注释状态（阶段 6 中），图片统一走阶段 5 的变体卡片装配。
- 所有外部 API 调用（AI 翻译、物流比价等）均实现 3 次重试，防止偶发网络问题。
